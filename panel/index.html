QBLOGG PANEL

İçerik paneli

Bu panel GitHub'a doğrudan yazar — değişiklikler her zaman bir Pull Request veya Issue olarak açılır, doğrudan main'e commit atmaz. Giriş için bir GitHub kişisel erişim jetonu (PAT) gerekir.

Yalnızca bu depoya kapsamlı, fine-grained bir jeton kullanın: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new. Repository access: yalnızca BETA-ART-PRIVAT. Permissions: Contents: Read and write, Issues: Read and write, Pull requests: Read and write. Süre: kısa tutun (ör. 30-90 gün). Jeton yalnızca bu sekmenin belleğinde tutulur (sessionStorage) — sekmeyi kapatınca silinir, hiçbir sunucuya gönderilmez, GitHub API'sine gitmesi dışında.
