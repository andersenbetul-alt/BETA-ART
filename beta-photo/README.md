# beta-photo

**BETA PHOTO – verifisert kunstfotografi**  
Signerte og nummererte kunstfotografier med dokumentert opprinnelse og unik BETA-ID.  
Galleri, verifiseringssystem, begrenset opplag (maks 20 per motiv).
