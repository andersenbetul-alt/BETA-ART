# NAVIAR Logo Projects — Skills and Clearance Stack v1.0

Date: 2026-08-24  
Scope: NAVIAR-001 through NAVIAR-026 and all NAVIAR sub-brands  
Rule: **No project may be labelled FINAL, v1.0-LOCKED, or TESCİLE HAZIR until every mandatory gate below is evidenced and passed.**

| Stage | Skill/capability | Required output | Status rule |

| Visual audit | `product-design:audit` | Screenshot-backed hierarchy, readability and accessibility review | Open critical findings block approval |

| Design feedback | `canva:canva-design-feedback` | Independent layout/readability feedback | Advisory evidence |
| Marketing adaptation | `canva:canva-edit-design` + `canva:canva-resize-for-social-media` | Approved social/digital variants | Only after master approval |
| Mockups | `adobe-create-mockups` | Print, signage, device and merchandise proofs | Never included in the filing representation |
| Campaign variants | `adobe-create-social-variations` | Platform-specific approved adaptations | Only after master approval |

## 3. Official trademark clearance sources

### Norway — Patentstyret

- Main source: https://www.patentstyret.no/
- Norwegian registry search: https://search.patentstyret.no/advanced/
- Databases and registers: https://www.patentstyret.no/sok-databaser
- Official pre-search services: https://www.patentstyret.no/varemerke/tjenester/forundersokelser
- Application preparation: https://www.patentstyret.no/varemerke/forbered-varemerkesoknad

Mandatory use:

1. Search identical and similar word marks in Norway.
2. Search figurative marks and relevant Vienna elements.
3. Record application/registration number, owner, status, classes and source date.
4. Check Brønnøysundregistrene, Norid and open-web use because official pre-searches do not cover every unregistered sign used in Norway.
5. Decide separately whether to file word and figurative marks; they require separate applications.

### European Union — EUIPO

- Main source: https://www.euipo.europa.eu/en
- Availability and TMview: https://www.euipo.europa.eu/en/trade-marks/before-applying/availability
- EUIPO searches: https://www.euipo.europa.eu/en/search-ip
- TMclass: https://euipo.europa.eu/ec2
- Representation guideline: https://guidelines.euipo.europa.eu/2302857/2226461/trade-mark-guidelines/9-1-representation

Mandatory use:

1. Search the word mark and spelling/phonetic variants in TMview.
2. Upload the logo for image-similarity searching where available.
3. Validate exact goods and services through TMclass/HDB terminology.
4. Keep the filing representation to one mark and no additional information.
5. Validate the current electronic attachment requirements immediately before filing.

### International — WIPO

- Main source: https://www.wipo.int/portal/en/
- Global Brand Database: https://www.wipo.int/en/web/global-brand-database
- Global Brand Database user guide: https://www.wipo.int/documents/d/global-brand-database/docs-en-user-guide.pdf?download=true
- AI tools and image similarity: https://www.wipo.int/en/web/ai-tools-services

Mandatory use:

1. Search exact, fuzzy, phonetic and spelling variants.
2. Run image similarity using the proposed flat logo master.
3. Obtain and record relevant Vienna Classification suggestions.
4. Filter results by Nice class, country/office, status, owner and date.
5. Search national/regional registers separately because WIPO warns that the Global Brand Database is not a complete real-time display of every global mark.

## 4. Required search sequence for every logo

1. **Identity:** exact word, spacing and punctuation.
2. **Variants:** phonetic, visual, spelling, translation and truncation variants.
3. **Services:** exact Nice classes and accepted goods/services terms.
4. **Norway:** Patentstyret + company name + domain + open-web use.
5. **EU:** TMview/EUIPO + TMclass.
6. **International:** WIPO Global Brand Database + Vienna/image search.
7. **Design QA:** colour, monochrome, reverse, 250 px, 120 px, 32 px, 24 px and 16 px.
8. **Production QA:** screen, ordinary office print, one-colour print and low-quality reproduction.
9. **Rights:** applicant, designer assignment, fonts/assets licences and parent-brand permission.
10. **Lock:** dated approval, source hashes and `v1.0-LOCKED` only after every gate passes.

## 5. Evidence record required for each search hit

- Project number
- Mark searched
- Search variation
- Registry/source
- Search date and time zone
- Territory
- Nice class
- Vienna code where relevant
- Record/application number
- Owner/applicant
- Status
- Word, phonetic, conceptual and visual similarity assessment
- Goods/services overlap
- Risk rating
- Direct source link or exported official report
- Reviewer and decision rationale

## 6. Stop conditions

The project remains `REVISE / FILING HOLD` if any of these applies:

- Live registry searches are incomplete or undated.
- The applicant or ownership chain is unclear.
- Nice terms are not final.
- A high-risk earlier mark has not been assessed.
- The filing image differs from the approved master.
- Small-size, monochrome or reverse tests fail.
- Font, image or asset licensing is undocumented.
- The upload file fails the latest technical requirements.
- Final approval and source-hash lock are absent.

This workflow reduces risk but does not guarantee registration. Final registrability decisions belong to the relevant office, and legal advice may require a qualified IP professional.
