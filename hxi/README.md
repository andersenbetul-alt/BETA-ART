# HXI — Official Website

Official website of HXI (Christoffer Andersen), Norwegian phonk producer.

- **Live**: [hxi-nordic-pulse.lovable.app](https://hxi-nordic-pulse.lovable.app)
- **Lovable project**: `hxi-nordic-pulse` (`2bae4f70-cf5f-4b05-bd04-8cf9d26ad9bb`)
- **Lovable workspace**: Betül's Lovable
- **Snapshot**: commit `c7faa2a04c08c0778faa3f178d43fe6aba654cc7` (Aug 24 2026)

## Stack

- **TanStack Start** (SSR, file-based routing)
- **React 19** + TypeScript
- **Tailwind CSS v4** (zero-radius, dark-only)
- **shadcn/ui** (new-york style, all components)
- **Bun** runtime

## Design system

## Getting started

```bash
# Install (Bun preferred)
bun install

# Dev server
bun run dev

# Build
bun run build
```

> **shadcn/ui components**: The `src/components/ui/` directory holds standard shadcn
> components generated by Lovable. If you need to regenerate them:
> ```bash
> bunx shadcn@latest add --all
> ```
