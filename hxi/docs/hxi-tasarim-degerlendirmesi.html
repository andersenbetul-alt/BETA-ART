Strateji

NE YAPILMALI

01

V6'YI DEPLOY ET

HXI V6 şu an monorepo'da tam oturan, i18n'li, real varlıklara sahip, 10 bölümlü en olgun versiyondur. Vercel'de hxi-v6 projesi aç, hxi-v6/ klasörünü root olarak ayarla, Next.js preset ile deploy et. Bu iki komut işi bitirir.

02

V1 İÇERİĞİNİ TAŞI

Stem satışı, NCS bölümü ve 5 kademeli sync fiyat tablosu V1'de yazılıydı, hiçbir sonraki versiyona taşınmadı. Bu bölümleri V6'nın i18n altyapısına uyarlayarak ekle. Gelir bölümleri olmadan site tanıtım sayfasından öteye geçemiyor.

03

V4'Ü ARŞİVLE

V4, V1'in küçük bir Spotify ID düzeltmesiyle kopyasıdır. Monorepo'da yer kaplıyor. archived/hxi-v4/ klasörüne taşı veya README ile arşiv olarak işaretle. V2 de aynı değerlendirme: TanStack'te kalan tek özgün katkı Supabase entegrasyonu, onu Next.js'e taşıyabilirsin.

04

ARKTISK'İ SAKLA

HXI-7 Arktisk konsepti farklı bir yön — elektrik mavisi, Space Grotesk. V6 olgunlaştıktan sonra yeni bir albüm veya marka dönüşümü için değerlendirilebilir. Şu an öncelik değil; artifact olarak arşivde dursun.

Kısa Eylem Listesi

  1. Vercel'de hxi-v6 projesi aç — Root Directory: hxi-v6, Framework: Next.js
  2. GitHub bağlantısı kur — andersenbetul-alt/BETA-ART → hxi-v6 klasörü → push başına deploy
  3. V1 bölümlerini taşı — Stems (3 ürün), NCS (50M), Sync (5 kademe + form) → locales.ts'e ekle
  4. hxi.no domain bağla — Vercel panel + GoDaddy CNAME, MX kayıtları GoDaddy'de kalır
  5. V4 arşivle, V2 not düş — Temizlik commits
