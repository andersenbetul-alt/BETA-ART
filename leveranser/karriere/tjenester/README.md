# Tjenestespesifikasjoner

Hva hver betalte tjeneste faktisk inneholder — skrevet for rådgiveren som skal
levere den, og for kunden som skal vite hva de har kjøpt.

**Rådgiveren gjør det som står her, og ikke noe mer.** Ser du noe utenfor
oppdraget, sier du fra til NAVIAR; du utvider ikke jobben på egen hånd.

Reglene i `../README.md` gjelder alt sammen: ingen oppdiktet erfaring, ingen
garanti om jobb eller intervju, ingen rettslig, helsefaglig eller økonomisk
rådgivning, og kunden godkjenner og sender alt selv.
