## Standard deliverable specs from HXI

| Format | Spec |
|---|---|
| Mastered WAV | 24-bit / 44.1 kHz stereo |
| Mastered MP3 | 320 kbps |
| Streaming target | –14 LUFS integrated (Spotify/Apple/YouTube) |
| CD target | –9 to –11 LUFS, true peak ≤ –0.3 dBTP |
| Vinyl target | discuss with engineer — depends on cut |

## What to send to HXI for mix

- Exported stems or tracks: WAV, 24-bit, 48 kHz or higher
- Name tracks clearly (e.g. `Kick_01.wav`, `Lead_Vox_Dry.wav`)
- Include a rough mix for reference
- Note any FX you want kept on prints vs. sent dry

## What to send for mastering

- Stereo mix: WAV, 24-bit, 44.1 kHz or higher
- Leave 1–2 dB headroom (no limiting or heavy compression on the bus)
- Include a reference track if you have a target sound
