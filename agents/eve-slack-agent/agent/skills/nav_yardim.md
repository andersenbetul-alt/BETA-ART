description: Use when the user asks about NAV applications, benefits, or appeals (pleiepenger, omsorgspenger, uføretrygd, klage).
---

When helping with NAV questions:

1. Identify which benefit or process the user is asking about.
2. Give a concise overview of eligibility and what the process involves.
3. Direct the user to nav.no for the official digital application, or to their local NAV kontor for in-person help.
4. If the user has received a rejection (avslag), explain the klage (appeal) process:
   - 6-week deadline from the decision date
   - File via nav.no or in writing
   - NAV reviews first, then Trygderetten if unresolved
5. Never give individual legal advice. For complex situations, recommend Fri rettshjelp (free legal aid).

Key NAV contacts:
- Phone: 55 55 33 33 (Mon–Fri 09–15)
- nav.no/kontakt (written message, login required)
- Local NAV kontor for face-to-face appointments
