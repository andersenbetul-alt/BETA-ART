---
name: brand-identity
description: Generate, audit, and document BETA-ART brand identity assets — CODDAN, COBBANI, NAVIAR SVG/PNG files via Python build scripts. Use when asked to regenerate logos, check brand file integrity, update brand colors or geometry, or add a new brand to the system. Also covers QBLOGG global brand assets (marka-uret.py).
---

Every brand lives under `brand/<name>/` with a `build.py` that generates all SVGs deterministically. QBLOGG's global assets are generated by `scripts/marka-uret.py`. No manual drawing — every file is a script output.

## Structure

```
brand/
  coddan/
    build.py          # CODDAN generator: C-bracket mark + wordmark
    master/           # generated SVGs (12 files)
    index.html        # contact sheet (preview all variants)
  cobbani/
    build.py          # COBBANI generator: BB monogram + wordmark
    master/           # generated SVGs (14 files)
    index.html        # contact sheet
  naviar/
    build.py          # NAVIAR generator
    master/
    descriptor/
    index.html

scripts/
  marka-uret.py       # QBLOGG brand: symbol + lockups + favicons (14 assets)
  marka-tescil.mjs    # Trademark registration file generator (EUIPO format)

assets/brand/         # QBLOGG outputs land here
docs/logo-sistemi.md  # Geometry rationale for QBLOGG brand
docs/marka-tescili.md # Trademark registration notes
```

## Prerequisites

```bash
pip install fonttools brotli -q  # for marka-uret.py (QBLOGG)
# brand/<name>/build.py scripts: stdlib only, no extra deps
```

## Generate assets

### Regenerate one brand

```bash
cd brand/coddan && python3 build.py
cd brand/cobbani && python3 build.py
cd brand/naviar  && python3 build.py
```

Or via the run-brand driver:

```bash
python3 .claude/skills/run-brand/driver.py build coddan
```

### Regenerate all (QBLOGG + all sub-brands)

```bash
python3 .claude/skills/run-brand/driver.py build all
```

This runs `scripts/marka-uret.py` then each brand's `build.py`.

### QBLOGG global assets only

```bash
python3 scripts/marka-uret.py
# or
npm run marka
```

Output: `assets/brand/` — 11 SVGs + 3 PNGs + `MANIFEST.md`

## Verify output

After generation, run the brand smoke test:

```bash
python3 .claude/skills/run-brand/driver.py smoke /tmp/brand-run
```

All 6 contact-sheet screenshots (3 brands × 2 themes) must be >10 KB.

## Trademark registration files

```bash
node scripts/marka-tescil.mjs
# or
npm run tescil
```

Generates EUIPO-format JPEG files. Requirements: JPEG, max 2835×2010 px, 96–300 DPI, <2 MB, RGB/Grey/B-W/CMYK. Details in `docs/marka-tescili.md`.

## Adding a new brand

1. Create `brand/<new-name>/build.py` following the `brand/coddan/build.py` pattern:
   - Define palette constants at top
   - Use H=100 coordinate grid
   - Generate into `master/` subdirectory
   - Print `✓ file (size)` for each output

2. Create `brand/<new-name>/index.html` contact sheet (copy coddan/index.html, adjust palette + logo refs)

3. Add to `BRANDS` list in `.claude/skills/run-brand/driver.py`

4. Run smoke test: `python3 .claude/skills/run-brand/driver.py smoke /tmp/brand-run`

## Gotchas

- Scripts are run from their own directory (`cd brand/coddan && python3 build.py`) — paths are relative to that directory.
- `marka-uret.py` samples the Inter variable font from `assets/fonts/` at wght=700; that font file must exist.
- All outputs should be byte-identical on re-run (deterministic). If not, check for random seeds or timestamps in build.py.
- Brand assets committed to repo; never commit an empty `master/` directory.
