# Put the real framework here

The `/performance-review` skill refuses to run until these three files exist
with real content. This is deliberate: the skill quotes rating definitions
verbatim and never invents criteria, so the organisation's own words must be
here first.

| File | Format |
|---|---|
| `competencies.md` | One `## Competency name` per competency, the organisation's description underneath |
| `ratings.md` | One `## Rating label` per level, the verbatim definition underneath |
| `template.md` | The review document's section headings (`## …`), in order, with any fixed boilerplate |

Paste from the HR handbook, don't paraphrase — the skill will quote these
files word for word. When the framework changes, change it here; every review
drafted after that uses the new text.
