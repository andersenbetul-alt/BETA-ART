# Cerceve — IK doldurur, ajan doldurmaz

Bu klasordeki uc dosya sirketin kendi materyalidir. **Buraya ornek,
taslak veya "gecici" icerik konmaz.** `check-framework.mjs` yer tutucu
tespit ederse degerlendirmeyi baslatmaz.

| dosya | ne icerir |
|---|---|
| `competencies.md` | Degerlendirilecek yetkinlikler. Bu listede olmayan hicbir sey puanlanmaz. |
| `ratings.md` | Her puan seviyesinin tanimi. Degerlendirmede **kelimesi kelimesine** alintilanir; ozetlenmez, yumusatilmaz. |
| `template.md` | Sirketin degerlendirme sablonu. Cikti bu sekli alir. |

Kaynak: IK'nin yayimladigi guncel surum. Surum ve tarih dosyanin basina
yazilsin ki hangi cerceveye gore puanlandigi sonradan belli olsun.
