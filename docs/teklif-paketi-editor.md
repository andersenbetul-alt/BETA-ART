# Teklif paketi — İçerik Editörü (finalist için, ŞABLON)

Tarih: 25.08.2026 · Durum: **finalist yok** — rol ilanı 3 ücretli pilot
kanıtına bağlı (docs/rol-icerik-editoru.md). Bu paket, finalist
çıktığında doldurulacak hazır kittir. Hiçbir alan uydurulmamıştır;
boşlar [DOLDURULACAK] ile işaretlidir.

## 1. Teklif alanları (onayınıza sunulacak)

| Alan | Değer |
|---|---|
| Aday adı | [DOLDURULACAK] |
| Rol / biçim | İçerik Editörü — serbest, iş başına (rol-icerik-editoru.md) |
| Pilot başına ücret | [DOLDURULACAK] NOK (birim önerisi: sabit, saatlik değil) |
| Ücretli deneme görevi | 1 Action Page sonuç metni editörlüğü — [DOLDURULACAK] NOK |
| Editör penceresi (SLA) | Teslimden itibaren 48 saat |
| Ödeme vadesi | [DOLDURULACAK] gün (faktura, aday kendi org.nr/frilans kanalıyla) |
| Dil kapsamı | İnsan editörlüğü NO + EN (öneri — sizin onayınız bekliyor) |
| Telif | Teslim edilen düzeltmelerin hakları QBLOGG'a devredilir — sözleşme maddesi avukat teyidinde (hukuk-kontrol.md) |
| Başlangıç | [DOLDURULACAK] (ilk pilot teslim takvimine bağlı) |
| Teklifin geçerlilik süresi | [DOLDURULACAK] (öneri: 7 gün) |
| 90. gün görüşmesi | Hacim düzenliyse aylık saat anlaşmasına geçiş görüşülür |

Dürüstlük maddesi (teklifte açıkça söylenecek): iş hacmi pilot
satışlarına bağlıdır; garanti edilen aylık hacim yoktur.

## 2. Sıcak e-posta taslağı (aramayı kuran; Norveççe)

Konu: **Vi vil gjerne jobbe med deg — har du 20 minutter?**

> Hei [navn],
>
> takk for samtalene så langt — vi har bestemt oss, og vi vil gjerne
> jobbe med deg som frilans innholdsredaktør for QBLOGG.
>
> Jeg vil helst gå gjennom tilbudet sammen med deg i en kort videosamtale
> i stedet for å sende alt på e-post: rollen, tallene og hvordan
> samarbeidet fungerer i praksis. Det tar rundt 20 minutter.
>
> Passer [dag] kl. [tid], eller foreslå gjerne et tidspunkt som passer
> deg bedre.
>
> Vi gleder oss.
>
> Vennlig hilsen
> Betül — QBLOGG

(Not: e-postada rakam yok — bilinçli; rakamlar görüşmede sunumla
anlatılır, yazılı teklif görüşmeden sonra gönderilir.)

## 3. Görüşme sunumu

`docs/teklif-sunumu-editor.html` — tarayıcıda açıp ekran paylaşılır;
ok tuşlarıyla ilerler. 6 sayfa: rol → çalışma biçimi → rakamlar
([FYLLES UT]) → dürüstlük maddesi → "neden sen" (görüşme notlarınızdan
üç somut gerekçe girilecek — şablon boş, övgü uydurulmaz) → 90 gün +
sonraki adımlar.

## 4. Göndermeden önce kontrol listesi

1. Ücret alanları dolduruldu ve Norveç serbest piyasasından doğrulandı.
2. Sözleşme şablonu avukat teyidinden geçti (telif + gizlilik + tazmin).
3. "Neden sen" sayfasına görüşmeden üç gerçek gözlem yazıldı.
4. Dil kapsamı kararı (NO+EN önerisi) onaylandı.
5. Teklifin geçerlilik tarihi sunuma ve e-postaya işlendi.
