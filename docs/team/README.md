## Hvilken modell dokumentet beskriver

Prosjektet har byttet modell én gang: fra åpen markedsplass til B2B-verktøy for
tjenesteleverandører. Dokumentene er merket deretter.

| Merking | Betyr |
|---|---|
| Ingen merking | Gjelder produktet vi selger nå |
| Gul boks øverst | Skrevet for markedsplassen. Deler gjelder, men forutsetningene gjør det ikke |
| `docs/arkiv/` | Gjelder ikke. Beholdt fordi regnestykkene var riktige for sin modell |

Grensen for hva vi gjør og ikke gjør står i `../JURIDISK-GRENSE.md`.

Rammene alle arbeider innenfor står i `../TEAM.md`.

Er du usikker på hva som gjelder, er **`../JURIDISK-GRENSE.md`** fasit: den sier hva
tjenesten gjør, hva den ikke gjør, og hvorfor. `SYNTESE.md` var fasit under
markedsplassmodellen og viser nå hvilke av de elleve beslutningene som overlevde.

De øvrige dokumentene er fagpersonenes grunnlag.
