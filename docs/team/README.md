# Teamleveranser

Hver rolle i `.claude/agents/` leverer sitt bidrag her. Dokumentene er
arbeidsdokumenter fra fagpersonene, ikke vedtatt policy.

| Fil | Rolle | Innhold |
|---|---|---|
| `TJENESTEDESIGN.md` | Tjenestedesign | Gap-analyse: hva mangler før pilot med ekte brukere |
| `TEKNOLOGI.md` | Teknologi | Arkitektur for fase 2: stack, datamodell, API, migrering |
| `KI.md` | KI | Veikart for modellbruk, med sikringene som må følge med |
| `TEKST.md` | Copywriting og UX | Tekstgjennomgang: gammel → ny, med begrunnelse |
| `MERKEVARE.md` | Merkevare | Merkeplattform, navnevurdering for Europa, tone of voice |
| `MARKEDSFORING.md` | Markedsføring | Go-to-market for Oslo-piloten |
| `SALG.md` | Salg | Abonnementsnivåer, arbeidsgiver- og kommunespor, innvendingsark |
| `OKONOMI.md` | Økonomi | Enhetsøkonomi, følsomhet, kapitalbehov |
| `SYNTESE.md` | Koordinering | Der rollene er uenige, og hva som velges |

Rammene alle arbeider innenfor står i `../TEAM.md`.
