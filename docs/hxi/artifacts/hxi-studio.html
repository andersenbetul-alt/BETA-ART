Slack Botu — hxi-music

İki Vercel deployment aynı kodu paylaşır. AGENT_PROFILE env değişkeni bot kimliğini belirler.

# Vercel Dashboard → Settings → Environment Variables
# hxi-music projesi:
AGENT_PROFILE=hxi-music

# naviar-consult projesi:
AGENT_PROFILE=naviar-consult

# Yerel geliştirme:
AGENT_PROFILE=hxi-music pnpm dev
hxi-music ●

Müzik prodüksiyon stüdyosu asistanı. Mix, mastering, teknik format soruları, proje kapsamlandırma.

naviar-consult

Organizasyon danışmanlığı botu. Henüz taslak aşamasında — içerik ve kapsam girilmedi.

Bot Skill'leri

proje-on-degerlendirme

Müşteri proje anlatımında devreye girer. Track sayısı, aşama, format ve deadline'ı sorar; sonraki adımı netler.

teknik-format

Format, sample rate, loudness target ve stem hazırlık soruları için standart teknik bilgi tablosu.
