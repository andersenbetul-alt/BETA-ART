# Ekip modeli — 20 rol listesinin QBLOGG karşılığı

Tarih: 24.08.2026. Kullanıcı, başka bir yapay zekânın "profesyonel web
ekibi" listesini iletti (20 rol; 7–9 kişilik çekirdek önerisi). Dürüst
değerlendirme:

## Ana tespit

QBLOGG bugün **tek kurucu + yapay zekâ** operasyonudur ve ödeme kanıtı
öncesinde (30 günlük Action Pages kapısı) hiçbir işe alım savunulamaz.
Rol listesi işe alım planı olarak değil, **denetim mercekleri** olarak
değerlidir: her rol, işin bir kalite kapısıdır ve çoğunun karşılığı
depoda zaten çalışır durumda.

## Rol → mevcut mekanizma eşlemesi

| Rol (listeden) | QBLOGG karşılığı bugün |
|---|---|
| Product Manager | Kullanıcı (kararlar) + proje günlüğü/ROADMAP |
| Business Strategist | docs/is-modeli.md + yazar-platformu.md süreci |
| UX/UI/Brand Designer | Tasarım sistemi (docs/tasarim-sistemi.md), marka betikleri |
| UX Writer / Copywriter | qblogg-blog-yazisi + i18n sözlük disiplini |
| Frontend/Backend/Tech Lead | Bu oturumlar (statik site + uye/ Supabase) |
| SEO Specialist | gorunurluk.mjs + sitemap/hreflang/RSS hattı |
| CRO Specialist | **boşluk** — ölçüm yok (bilinçli: veri asgari); pilotta elle ölçülür |
| Data Analyst | **boşluk** — veri toplanmıyor; pilot ölçümü görüşme notlarıyla |
| QA/Test | check.mjs + Playwright sürüşleri (run-qblogg) |
| Accessibility | C3 ölçütü + RTL/kontrast kuralları (denetimlerde) |
| Cybersecurity | guvenlik.mjs (13 denetim) + CSP'ler |
| GDPR/Privacy | gizlilik.html + veri-asgari tasarım; **avukat teyidi açık iş** |
| Growth/Marketing | **kullanıcı tarafı** (satış görüşmeleri, LinkedIn) |
| Mobile Developer | gerek yok (duyarlı web bilinçli tercih) |
| Service Designer / UX Researcher | pilot görüşmeleri bu işi görür (10 danışman) |

## Ne zaman gerçek işe alım

- İlk gerçek ihtiyaç sırası (gelir geldikçe): **editör/yazar** (içerik
  hattı satılırsa teslimat kapasitesi) → **satış/growth** → tasarımcı.
- Listedeki Trust & Safety + Accessibility + GDPR uzmanlarının "kritik"
  notu, yaşlı bakım platformu bağlamı (NAVIAR CARE) içindir; o proje
  gerçek kullanıcı verisiyle çalışmaya başlarsa bu üç rol gerçekten
  danışmanlık olarak satın alınmalıdır — QBLOGG statik sitesi için değil.
- 7–9 kişilik "çekirdek ekip" bile bugünkü aşama için erkendir; önce
  3 ücretli pilot (docs/action-pages-teklif.md), sonra ekip konuşulur.
