# Registering "HXI"

Procedure, not legal advice. Fees checked August 2026 and they move — confirm on the offices'
own pages before paying anything.

## Why this is first on the business list

The name is the asset every other one hangs from. A store is about to sell goods under it, a
domain points at it, and a catalogue is credited to it. Right now nobody owns it as a mark,
which means the first person to file can — including someone who noticed it selling.

It is also cheap. A Norwegian filing is in the low thousands of kroner. Losing the name is not.

## Step 0 — search before you spend

Free, and it decides whether the rest is worth doing.

- **TMview** (`tmview.org`) searches most registers at once, including Norway and the EU.
- **Patentstyret's own search** for Norway.
- **EUIPO eSearch** for the EU.

Look for `HXI` and near-misses in the classes below. A three-letter mark in music is exactly
the shape that collides — if something is already registered, that is far better learned now
than after a filing fee and a refusal.

## Step 0.5 — establish who is allowed to file

**This one is specific to HXI and it comes before the paperwork.** The artist's own brand pack
records the Scar Scheme Records contract as signed under the name "HXI", with master rights
and name ownership *unresolved*. If the label has any claim to the name, a filing in the
artist's personal name can be opposed — and a label that reads the same contract could file
first.

A lawyer reading that contract is the prerequisite. It is the same reading that settles the
GramArt question, so it is one appointment for two answers.

A filing needs a named owner. In Norway a private individual can hold a trademark, so no
company is required first — but if an ENK or AS is coming later, decide now, because assigning
a mark afterwards is extra paperwork.

## The classes

Goods and services are split into 45 Nice classes, and you pay per class. For a producer who
records, performs and sells merch, three matter:

| Class | Covers | Why |
| --- | --- | --- |
| **41** | Entertainment services, live performance, DJ sets | The core one for an artist name |
| **9** | Recorded and downloadable music, audio files | The releases, the stems, the sample packs |
| **25** | Clothing, headwear | The tee, the hoodie, the cap |

The **13th edition of the Nice Classification came into force on 1 January 2026**, so wording
from an older guide may no longer match. Use the office's pre-approved terms — in Norway it
also buys a much faster answer.

Class 25 is worth filing only if merch is actually happening. Three classes is not three times
the work, but it is real money, and an unused class is a class someone can attack later for
non-use.

## Norway first — Patentstyret

- **Basic fee: NOK 3,800** for one class. Through an agent or law firm, budget roughly
  **NOK 9,800 excl. VAT** for a single-class filing including that fee.
- **Term: 10 years** from the application date, renewable. Renewal starts around NOK 3,400.
- **Speed: about 3 weeks** for a first response if you pay at submission and use pre-approved
  terms. Otherwise up to **4 months** after payment arrives.

Norway first for three reasons: it is home, it is cheap, and it starts the clock below.

## Then the EU — and the six months that matter

**File the EU application within six months of the Norwegian one and it can claim the Norwegian
filing date.** That is the Paris Convention priority right, and it is the single most valuable
mechanical detail here: six months to see whether the name is worth defending abroad, without
losing the earlier date to anyone who filed in between.

EUIPO fees, online:

| | |
| --- | --- |
| First class | **€850** |
| Second class | **+€50** |
| Each class from the third | **+€150** |

So classes 41 + 9 + 25 is €850 + €50 + €150 = **€1,050**.

The **EUIPO SME Fund** runs a trade mark voucher scheme that reimburses part of these fees for
small businesses. It is worth checking before filing — it is an annual programme with limited
funds and it opens and closes on its own schedule.

## Beyond the EU

The **Madrid Protocol** (WIPO) lets one application designate many countries from a home
registration, paying a basic fee plus each country's own. Worth it when there is a reason —
merch selling into the US, a sync deal in a specific market. Not worth it speculatively.

## The order

1. Search TMview. Free. Do it today.
2. Get the Scar Scheme contract read. Blocks everything else.
3. File Norway, classes 41 and 9 — and 25 if merch is real.
4. Diary the six-month date the moment the Norwegian filing goes in.
5. Decide on the EU before that date passes.

## What this does not cover

Whether HXI *may* file, given the label contract, is a legal question with a real answer that
only a lawyer reading the contract can give. Everything above is what to do once that answer
is yes.
