# NAVIAR Care — Yardımcı seçim kartı

Kaynak: Pilot Implementation Plan, Task 2 Step 1. Hedef: 8-12 aday havuzundan
**5-8 onaylı pilot yardımcısı**. Havuz bilinçli olarak küçük tutuluyor —
niceliğin değil, güvenin önceliği var.

**Not (tjenesteutvikler bakışı, medarbeideropplevelse):** bu kart yalnızca bir
eleme aracı değil — adayın ilk temas noktası. Süreç boyunca netlik ve saygı,
işe alınmayan adaylarda bile NAVIAR'ın marka izlenimini belirler.
