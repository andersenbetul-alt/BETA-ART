# NAVIAR Care — Haftalık pilot kartı

Kaynak: Pilot Implementation Plan, Task 5 Step 1-3. Her hafta 30 dakikalık
kalite/risk toplantısında doldurulur ve gözden geçirilir (kurucu tarihleri
ve kapanış kanıtını sahiplenir; güvenlik danışmanı her ciddi endişeyi
inceler).

## Kohort büyüme kuralı

- 1. hafta: en fazla 5 aile
- Sonraki her hafta: en fazla +5 yeni aile, **ancak** personel/seyahat
  süresi/nöbet iki hafta üst üste plan dahilinde kaldıysa
- Her yeni aile: insan kurulum görüşmesi + hizmet alan rıza onayı + ilk
  ziyaret kontrolü

## Haftalık ölçüt tablosu (her hafta yeni satır)

| Hafta | Yeni aile | Toplam aktif aile | Nitelikli-talep→ödeyen dönüşümü | Talep→ilk ziyaret süresi | Rezerve/gerçekleşen ziyaret | Zamanında varış | Tercih edilen yardımcı sürekliliği | Aile güncelleme rıza oranı | Hizmet alan memnuniyeti | Aile memnuniyeti | 4 haftalık devam | Şikayet oranı | Ciddi olay | Katkı marjı | Koordinatör saati / hizmet saati |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | | | | | | | |

**Not (planın ayrımı):** hizmet alan ve aile memnuniyeti **ayrı ayrı**
raporlanır — tek bir "müşteri memnuniyeti" satırına birleştirilmez, çünkü
bu iki tarafın çıkarları farklı olabilir (bkz. `product/consent-and-
communication-model.md`).

## Haftalık toplantı gündemi (sabit)

1. Tüm olaylar (bkz. `operations/incident-and-escalation-sop.md`)
2. Kaçırılan/geciken ziyaretler, ikameler, iptaller
3. Rıza değişiklikleri
4. Kapsam dışı talepler
5. Şikayetler
6. Teslim edilen saat başına doğrudan maliyet
7. Satış kaynağı performansı
8. Açık düzeltici aksiyonlar — kapanış kanıtıyla
