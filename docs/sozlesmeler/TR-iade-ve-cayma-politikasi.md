# İade, Değişim ve Cayma Politikası

## Özet

| | |
|---|---|
| Cayma süresi | Teslimattan itibaren **14 gün** (yasal) |
| COBBAN iade süresi | **30 gün** (yasal süreden daha uzun, marka politikamız) |
| İade kargo | İlk iade **ücretsiz** (anlaşmalı kargo ile) |
| Para iadesi | Ürün elimize ulaştıktan sonra **3 iş günü** içinde |
| Değişim | Beden/renk değişimi ücretsiz, 1 kez |

## Nasıl iade ederim?

1. `{{EPOSTA}}` adresine sipariş numaranla yaz veya `cobban.com/iade` sayfasındaki formu doldur.
2. Sana iade kodu ve kargo etiketi gönderelim.
3. Ürünü **orijinal ambalajı, etiketleri ve faturasıyla** paketle.
4. Anlaşmalı kargo şubesine iade kodunu vererek teslim et.
5. Ürün elimize ulaştıktan sonra kontrol edilip 3 iş günü içinde iaden yapılır.

## İade edilemeyen ürünler

- Ambalajı açılmış kozmetik, kişisel bakım ve hijyen ürünleri
- İç giyim, çorap, küpe
- Kişiye özel üretilen / isim yazılan ürünler
- İndirimli "son ürün" olarak işaretlenmiş kampanya ürünleri *(cayma hakkı saklıdır,
  yalnızca değişim yapılamaz)*
- Kullanılmış, yıkanmış, etiketi çıkarılmış veya hasar görmüş ürünler

## Hatalı veya hasarlı ürün

Ürün **ayıplı** ise (kırık, eksik, yanlış ürün):
- Teslimattan itibaren **30 gün** içinde bize bildir.
- Seçim senin: **ücretsiz onarım, değişim, bedel indirimi veya tam iade.**
- Tüm kargo masrafları bize aittir.
- Yasal ayıp sorumluluğu süresi **2 yıldır** (6502 sayılı Kanun).

## Para iadesi ne zaman hesabımda olur?

| Ödeme yöntemi | Süre |
|---|---|
| Kredi kartı | 3 iş günü içinde bankaya, bankadan kartına **1–3 hafta** (banka süreci) |
| Banka kartı | 3–10 iş günü |
| Havale/EFT | 3 iş günü içinde belirttiğin IBAN'a |
| Taksitli ödeme | Taksit sayısına göre bankan tarafından parçalı iade edilir |

## Yurt dışı siparişlerde iade

Yurt dışına gönderilen siparişlerde iade kargo bedeli müşteriye aittir.
Gümrük vergisi ödediysen, iadede bu tutarın geri alınması için ülkenin
gümrük idaresine başvurman gerekir; COBBAN bu tutarı iade edemez.
