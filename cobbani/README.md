# Cobbani

Cobbani, Beta Art bünyesinde geliştirilen bağımsız bir markadır.

**Alan:** cobbani.co  
**Durum:** Marka tasarımı tamamlandı, site geliştirme aşamasına geçilecek.

---

## Marka kimliği

### Renk paleti

| Ad | Hex | Kullanım |
|---|---|---|
| Çam Yeşili | `#12463C` | Ana marka rengi |
| Pirinç | `#9C7F45` | Tittle nokta (şeffaf zemin) |
| Pirinç Açık | `#C6A566` | Tittle nokta (koyu zemin) |
| Mürekkep | `#14181A` | Metin, mono logo |
| Kâğıt | `#F1F3F1` | Açık zemin |

### Yazı tipleri

| Rol | Yazı tipi |
|---|---|
| Başlık / kelime markası | Bodoni Moda |
| Gövde / arayüz | Instrument Sans |

### İşaret sistemi

Cobbani logosu iki parçadan oluşur:
1. **C işareti** — açık bir C yayı (Bodoni Moda oranlarına yakın geometri).
2. **Tittle nokta** — C'nin sağ açılımının ortasına yerleşen pirinç daire.
   Tittle, harfin bir parçası değil, markanın sesini taşıyan bağımsız öğedir.

## Brand dosyaları

```
cobbani/brand/
├── cobbani-isaret.svg              Bağımsız C işareti — şeffaf zemin, renkli
├── cobbani-isaret-beyaz.svg        Bağımsız C işareti — koyu zemin (beyaz)
├── cobbani-isaret-siyah.svg        Bağımsız C işareti — tek renk baskı (siyah)
├── cobbani-logo-yatay.svg          Yatay kilit — renkli (standart kullanım)
├── cobbani-logo-yatay-beyaz.svg    Yatay kilit — koyu zemin (beyaz)
├── cobbani-logo-yatay-siyah.svg    Yatay kilit — tek renk baskı (siyah)
├── cobbani-favicon.svg             Kare favicon — yeşil zemin, beyaz işaret
└── KAYNAK.md                       Yazı tipi lisansları ve kaynak kaydı
```

### Kullanım kuralları

- **Standart kullanım:** `cobbani-logo-yatay.svg` — açık zemin.
- **Koyu zemin:** `cobbani-logo-yatay-beyaz.svg`.
- **Tek renk baskı / damga / faks:** `cobbani-logo-yatay-siyah.svg`.
- **Favicon / simge:** `cobbani-favicon.svg` (512×512 kare).
- Logoyu yeniden renklendirmeyin; yalnızca bu dosyalardaki renkleri kullanın.
- C işaretini ve tittle noktasını birbirinden ayırmayın.
- Minimum boyut: yatay kilit için 120 px genişlik.
