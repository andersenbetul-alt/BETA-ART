# Beta Art Archive

Build a premium photography licensing website called Beta Art. The brand concept is an archive of verified human photography: every image is made by a human with a physical camera, the RAW original is preserved, capture metadata/provenance is kept, and licenses are issued directly by the photographer. Visual direction: minimalist museum/archive aesthetic, editorial typography, lots of whitespace, restrained premium feel, photography-first, not a generic SaaS landing page. Create a polished responsive homepage with: top navigation (Collection, Verification, Photographer, Licensing, FAQ, Contact); hero featuring 'Verified Human Photography' as the single H1, supporting copy about original human-made photography, documented provenance and direct licensing, and a primary CTA 'View the collection'; verification section with three methods (RAW original archived, capture record travels with the image, license signed by the maker); collection grid for 12 sample plates with title, catalogue number, location/date where available, and 'from kr 190'; photographer/about section; licensing overview with Personal, Commercial, Extended, and Custom & Exclusive; FAQ; and premium footer. Include SEO metadata: title 'Beta Art — Verified Human Photography & Licensing', meta description 'Discover original human-made photography with archived RAW files, documented provenance and direct licensing from the photographer.', canonical https://beta-art.com/, robots index,follow, Open Graph title/description/image placeholders, Twitter summary_large_image. Add structured data suitable for Organization/Person/Photographer, WebSite, ImageObject/Product where appropriate. Ensure semantic HTML, exactly one H1, accessible alt text on images, strong mobile responsiveness, fast-loading layout, and text rendered in crawlable HTML. Use placeholder photography with clear replacement points, and include the sample collection titles: First Light, Into the Pines, Sea of Fog, Still Water, PALM, Blue Hour Grid, Night Crossing, Golden Hour, Portrait in Amber, The Maker, Slow Morning, Low Tide. Use English copy throughout. Do not use AI-themed visuals; the site should feel like a serious photographic archive and licensing studio.
