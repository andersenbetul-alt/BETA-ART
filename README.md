# BETA-ART

Home page: **Naviar Care identity study** — four logo directions for a home and
elder care service, with palette, typography, usage rules and an interactive
scale test.

- `index.html` — the page itself, self-contained (no build step; open it directly
  or serve the folder with any static server).
- `brand/naviar-care/` — the artwork: SVG marks and lockups in colour, mono and
  reversed, transparent PNG exports, and a README with the palette and usage
  rules. `presentation.html` there is the same page in Artifact form.

The earlier multi-timezone clock demo was removed.
